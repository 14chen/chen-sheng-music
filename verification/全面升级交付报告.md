# 橙声君 · 全面功能修复与升级 交付报告

## 一、全局 UI 与音源调整
- **主题改橙色**：`main.dart` ThemeData colorSchemeSeed 从 deepPurple → deepOrange；浅色/深色模式自动适配；当前行高亮、标题、按钮均为橙色，对比度清晰
- **剔除 ccmixter**：删除 `src/sources/ccmixter.js`、探针文件；清理 `sources/index.js` 注册、`api.js` 代理路由与下载分支、`download.js` 音质分支、`url-guard.js`（无引用）、`test-p2.mjs` 相关用例。实测音源列表仅 `local, itunes, jamendo`
- **底部导航/侧边栏**：新增 4 个模块
  - 本地音乐（原曲目列表）
  - 下载管理（显示下载路径 + 跳转设置）
  - 最近播放（播放历史，去重置顶，最多100首）
  - 我的歌单（"我喜欢"默认歌单 + 自定义创建歌单）
  - 窄屏用 `NavigationBar`，宽屏用 `NavigationRail`

## 二、歌词模块重构
- **居中显示**：`lyrics_panel.dart` 用固定 `itemExtent=92` + `padding=(视口高-item高)/2`，当前行严格居中；非当前行 AnimatedOpacity/Scale 渐隐缩小
- **双语结构**：每行原文+译文，缺译标"无翻译"（斜体不冒充原文），中文歌不显示译文
- **同步**：绑定 `just_audio.positionStream`（高频真实进度），禁用 setTimeout 推进；offset 校准（±100ms 步进，持久化）
- **滑动 seek**：歌词区上下拖动 → 显示 `↕ mm:ss / mm:ss` 进度预览 → 松手回调 `onSeek` 跳转；拖动时暂停自动居中，松手后 300ms 恢复

## 三、下载与设置修复
- **下载错误细化**：`_explainDownloadError` 分类处理 DioException（connectionTimeout/sendTimeout/receiveTimeout/connectionError/badResponse 401/404/403/cancel）、SocketException、FileSystemException、FormatException，UI 显示具体原因（如"HTTP 401：口令错误"），不再只显示"下载失败"
- **设置增强**：三项齐全
  - 下载路径（查看/修改，持久化）
  - 清缓存（计算临时目录大小 + 一键清除）
  - 自定义音乐源（API 接口或插件路径输入）

## 四、响应式多端
- ≤768px：单列 + 底部导航；>768px：NavigationRail 侧边栏 + 主内容分栏（封面/歌词左右）
- 触摸：歌词滑动 seek、切歌手势均支持 touch（Flutter GestureDetector 原生）
- 按钮热区 ≥48px
