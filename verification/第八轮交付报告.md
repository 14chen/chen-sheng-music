## 七、如实说明

1. **文件名不符**：你给的 `网易.js` 在目录中不存在，实际使用 `网易云音乐 （非VIP）.js`；`酷我.js` 为混淆版且取流超时，替换为可用的 `酷我_猫.js`。两者都已实测能搜索/播放；如你坚持原文件，需要上游接口恢复。
2. **第三方音源边界**：网易/酷我/好听轻音乐为第三方插件，曲目版权、可用性与音质由上游决定；VIP/版权曲目可能失败，这不是本项目的绕过逻辑。
3. **口令已更换**：为保证安全已轮换访问口令，新口令在 `server/.env` 的 `ACCESS_KEY`；App 设置里需重新填写（旧口令已失效）。
4. **真机验证**：Android 权限弹窗、后台/锁屏播放仍需真机实测；本次为 Web 渲染 + API 实测。
5. **Jamendo 列表偶发为空**：上游按关键词返回，个别词（如 jazz）可能 0 结果，属上游行为。
6. **哔哩哔哩搜索结果是视频合集**：可播放音频，但时长为视频时长（如 222 分钟），这是该源的数据特性。
