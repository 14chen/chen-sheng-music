# 橙声音乐 · 歌词界面推倒重做 + 翻译质量修复 · 交付报告

## 阶段一：联网调研摘要（编码前完成）

### 酷狗概念版播放页特征
- 玻璃拟态（无边框、空灵通透）+ 封面色动态背景/光影叠加
- 多播放页样式切换：「歌词环游」「信笺歌词」「旋转封面」「唱片机模式」等，入口在播放页「…」
- 逐行高亮为主，当前行居中、字号最大；翻译开关在歌词区附近/「…」菜单

### 双语展示规范
- 原文上层（大、亮），译文下层（小、透明度低），紧跟原文成组
- 词条整体随时间轴轮播，译文不独立出现/消失
- 长译文换行而非截断

### 翻译质量问题根因（对应用户抱怨）
| 抱怨 | 根因 |
|---|---|
| 漏译、直接显示原文冒充翻译 | API 失败时静默 `|| 原文` 回退 |
| 半截无歌词 | ① 译文数组短于原文，前端按译文长度循环；② 译文未绑定原文时间区间 |
| 翻译效果差 | 逐词直译、未后处理、免费 API 噪声 |

### 技术选型
- Flutter 自绘 `LyricsPanel`（Theme colorScheme + AnimatedOpacity/Scale + ScrollController），参考 `flutter_lyric`/AMLL 的"词条整体"理念
- 翻译用 MyMemory 公开 API（免费无 key）+ 逐行校验 + 批量请求 + 后处理润色

## 阶段二：歌词界面推倒重做
- 新建 `lib/lyrics_panel.dart`：`LyricEntry`（原文+译文+time/endTime 整体）、`LyricsPanel` 组件
- 视觉层级：当前行最大最亮（紫 + 光晕），译文略小透明度低，非当前行缩小变暗
- 滚动：随播放进度平滑居中（animateTo），手动拖动后 900ms 自动回落
- 双语成组：原文+译文同属一个 Entry，整体轮播
- 空状态"暂无歌词"、缺译标"无翻译"（斜体）、中文歌不显示译文、可折叠
- 响应式：MediaQuery 宽度 ≥900 放大字号与行距

## 阶段三：翻译质量修复
- `lyrics-structure.js`：`buildEntries`（每行补 endTime，末行也有区间）、`alignTranslations`（逐行语言判断，缺译 null 不回退）、`polishTranslation`（去噪/空格/标点）、`validateAlignment`（统计 + 校验）
- `lyrics-translate.js`：**批量翻译（每批10行换行拼接，1次请求）** 解决限流；逐行语言判断（中文行跳过）；失败返回 null
- 关键 bug 修复：混合语言歌曲前几行是中文导致 `detectLang` 误判整首为中文而**漏掉后面所有外文行** → 改为逐行扫描判断
