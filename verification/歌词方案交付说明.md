# 《02的爱恋》《红笔》歌词加载 — 交付说明

## 目标（已达成）
曲库里这两首中文小众曲目，打开 App 播放页时**直接显示带时间轴的歌词**，无需手动操作、无需联网搜索。

## 联网调研结论（Firecrawl 未注册到本会话，用内置 websearch 完成）
搜了 AMLL 词库、LRCLIB、MiniMax/Suno/SenseAudio、网易云/QQ API 等方案：
- AMLL（开源歌词库）、LRCLIB：**都没有收录这两首**（实测 `api.amll.dev/v1/lyrics/search` 返回 total=0）
- MiniMax/Suno 等"歌词生成" API：是按主题**创作新歌词**，不是提取现有歌曲的歌词 → 不适用
- 网易云/QQ 非官方接口：绕过平台授权，按之前的边界不接
- **faster-whisper 语音识别**：对你自己拥有的音频做本地转录，合法、对任意歌曲有效 → 采用

## 实施方案（方案 B：Whisper 转录）
1. 用 `small` 模型转录两首音频（关 VAD + initial_prompt，实测《02的爱恋》从 5 行提升到 90 行）
2. 转成标准 `.lrc`，与音频同目录：
   - `小雪 - 红笔.lrc` — 17 行
   - `多多poi - 02的爱恋.lrc` — 90 行
3. 服务端已有"本地 .lrc 优先"逻辑，App 播放页有"歌词速览"组件，进页面即预加载显示

## 验证（实测 + 截图）
- API：`/api/lyrics` 两首都返回 `source: 本地 .lrc`（红笔 17 行、02的爱恋 90 行）、`hasLyrics: true`
- **截图**：`screenshots/lyric-hongbi.png`、`lyric-02ai.png`
  - 播放页封面下方灰色卡片直接显示歌词（时间轴 + 文本）
  - 无 console 错误，布局正常
  - 符合预期 ✅
- flutter test 19/19、analyze 无 error

## 重要说明（如实）
- 歌词是 **AI 语音识别结果**，不是官方歌词，存在识别误差/错字（如《02的爱恋》含日语段落，"darlin" 被识别成 "Darly" 等）——这是 Whisper 的固有局限，已是合法方案里的最佳结果
- 若你希望修正个别错字：点播放页歌词区的"编辑/添加"改成正确文本，保存到服务器即永久生效
- 以后导入新中文歌：先用 LRCLIB 自动抓（watcher 每 15 秒）；若匹配不到，运行：
  ```
  cd D:\work\music-app\server
  D:\Apps\viocestudio\VoiceStudio\project\.venv\Scripts\python.exe scripts\transcribe-lyrics.py --dir "D:\work\music-app\server\music"
  ```
  会自动为所有缺歌词的音频转录生成 `.lrc`（已在脚本中内置 tuned 参数）
