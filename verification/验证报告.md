## 任务一：单曲循环

- 新增 `PlayMode.single`，循环顺序 sequence→loop→shuffle→single→sequence。
- 核心逻辑抽成纯类 `lib/playlist_controller.dart`，UI 层 `Api.playMode` 持久化到 SharedPreferences。
- 边界处理：
  - 自动播完（ended/completed）→ single 返回当前下标，重播当前曲。
  - 手动点"下一首"→ 所有模式按列表前进，**不死锁**（单测专门覆盖）。
  - 手动点"上一首"→ 始终列表回退。
- 避免与播放器底层冲突：用 just_audio 的 `playerStateStream` 监听 `ProcessingState.completed`；切模式只改状态不切源；自动切歌发生在当前曲自然播完之后。

## 框架映射说明（用户任务书提到 Vue/React/CSS/Playwright）
本项目实际为 Flutter，映射关系：
- Vue/React 组件状态 → Dart `PlaylistController` + `Api.playMode`（SharedPreferences 持久化）
- CSS 媒体查询 / Tailwind 断点 → Flutter `LayoutBuilder` 的 maxWidth 断点（600/900）
- iOS Safe Area → Flutter `SafeArea` widget
- 暗黑模式 CSS 变量 → Flutter `ThemeMode.system` + `darkTheme`
- 触摸事件 touchstart/touchend → Flutter 原生手势（InkWell/IconButton），热区 48dp
- Playwright/Puppeteer → 本项目确实用了 Playwright（capture.mjs）做真实无头浏览器验证
