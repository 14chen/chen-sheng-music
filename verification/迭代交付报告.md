# 橙声音乐 → 橙声君 · 迭代交付报告

## 阶段一：调研摘要（编码前完成）

### 酷狗概念版播放页特征与复刻清单
- 玻璃拟态/无边框、背景随曲风变色；播放页样式入口在「…」菜单（星光彩胶/液体彩胶/歌词环游/旋转封面/信笺歌词/唱片机）
- 5.2.0 官方更新日志："新增左右滑动切歌"
- 复刻（红框功能不做）：用户信息/音乐Tab/收藏·最近·本地/歌单/底部导航；播放页头部+滚动歌词+控制栏+红心；本地列表；图四迷你卡片样式
- 不做：赚钱/免/邀好友VIP/提现/会员中心/免费听/AI作品/社区/已购/听歌时光机/我的云盘/发现/状态栏/评论/VIP提示

### 后台播放方案
- Android 官方：MediaSessionService + ExoPlayer 在 Service.onCreate 创建、onDestroy 释放；Manifest 声明 FOREGROUND_SERVICE + FOREGROUND_SERVICE_MEDIA_PLAYBACK；MediaSession 自动生成 MediaStyle 通知栏/锁屏控制；UI 用 MediaController 连接；API 33+ 需 POST_NOTIFICATIONS
- Flutter 对应：`audio_service` 插件（内部就是 Media3 MediaSessionService）+ just_audio
- iOS：Info.plist 配置 UIBackgroundModes: audio

### 卡片收缩交互
- Material 3 BottomSheet：collapsed/expanded 两态，下滑/点遮罩收起；上滑展开、下滑收缩；阈值约 100px；Material Motion 150–300ms ease-in-out；单一动画值驱动（共享元素避免闪烁）

### 体积优化手段
- R8 minifyEnabled+shrinkResources：ExoPlayer 贡献减约 40%
- ExoPlayer audioOnlyRenderersFactory + 最小 ExtractorsFactory（仅 mp3/flac/m4a）
- 仅引 media3-exoplayer 核心、resConfigs、WebP、ABI 过滤
- 注意：自定义 factory 必须用带参 Builder 构造器，否则 R8 无法裁剪默认工厂

### 技术栈对比
- 原生 Android(Kotlin+Media3)：体积最小、后台最成熟、单端
- Flutter（当前）：中体积、后台成熟（插件封装 Media3）、多端、开发效率高
- React Native：中偏大、后台中高、多端
- Tauri vs Electron：Tauri 比 Electron 小约 96%（实测 7.3MB vs 268.7MB）、内存低 75–90%

## 阶段七：技术栈选型（供你决定）
| 栈 | 包体积 | 后台播放成熟度 | 开发效率 | 迁移成本 |
|---|---|---|---|---|
| 保持 Flutter（现状） | 中(19MB with R8+arm64) | 高(audio_service 封装 Media3) | 高 | 0 |
| 迁移原生 Android(Kotlin+Media3) | 最小 | 最高(官方) | 中 | 极高（重写整个 App） |
| React Native | 中偏大 | 中高(三方) | 高 | 高（重写 UI） |
| Tauri(桌面) | 极小(~3MB) | 需自行封装 | 中(需 Rust) | 高（另起桌面端） |
- 建议：保持 Flutter，后台播放已由 audio_service 达到官方 Media3 同等能力，体积已优化到 19MB
