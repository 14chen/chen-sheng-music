# 歌词自动加载功能说明

## 效果
把音乐文件（mp3/flac/m4a 等）放进 `D:\work\music-app\server\music` 后：
1. watcher（每 15 秒）检测到新文件 → 自动扫描入库
2. 后台自动为该曲目从 LRCLIB 公开歌词库抓取歌词，保存为**同名 `.lrc`**（如 `歌名.mp3` → `歌名.lrc`）
3. App 曲目列表显示歌词标记（`hasLyrics`），打开播放页**自动预加载歌词并显示歌词速览**，点一下可看完整歌词（带时间轴）

## 实现
- `server/src/lyrics-fetcher.js`：核心模块（元数据读取 → LRCLIB 搜索 → 写 .lrc），带未匹配缓存（6 小时），避免反复请求
- `server/src/watcher.js`：检测到曲库变化后，后台异步补歌词（串行、每次间隔 400ms，最多 20 首/轮，不阻塞扫描）；服务器启动时也补一次
- `server/src/sources/local.js`：曲目列表返回 `hasLyrics` 字段
- `app/lib/track.dart`：Track 增加 hasLyrics
- `app/lib/main.dart`：播放页打开即 `fetchLyrics` 预取，内联显示歌词速览（前 4 行），切歌自动重新预取
- `scripts/fetch-lyrics.mjs`：手动批量脚本复用同一核心模块（`--dry-run` 不写文件）

## 验证（端到端实测）
- 放入 `The Beatles - Hey Jude.mp3` → 服务器自动生成 `The Beatles - Hey Jude.lrc`（首行 `[00:00.10] Hey Jude`）
- `/api/tracks?source=local&q=Hey Jude` → `hasLyrics: true`
- `/api/lyrics?id=...&title=Hey Jude` → `source: 本地 .lrc`、同步、101 行，秒出（无需联网）
- flutter test 19/19、analyze 无 error

## 重要说明（如实）
- **LRCLIB 是公开歌词库，主要覆盖主流/英文歌曲**。中文小众曲目（如你曲库里的《02的爱恋》《红笔》）可能匹配不到 → 无 `.lrc`，App 显示"暂无歌词"，可点歌词页的"编辑/添加"自己写一份（保存到服务器，永久生效）
- 若 LRCLIB 匹配不到且你希望自动生成，可用方案 B：`scripts/transcribe-lyrics.py`（faster-whisper 转录，需人声；纯音乐/无人声段无法生成）
- 导入音乐后，歌词生成有 15 秒检测延迟 + LRCLIB 请求耗时（几秒），稍等即出现
