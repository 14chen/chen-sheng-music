# 启动优化 + 图标更换 交付说明

## 一、启动慢的根因与修复

### 根因（诊断结果）
1. **main() 阻塞**：`await initAudioService(sharedPlayer)` 在 `runApp()` 之前，Android 上 Service/通知渠道初始化期间白屏
2. **默认地址错误**：真机默认 `http://10.0.2.2:18080`（模拟器地址），真机连不上 → 12s connect timeout
3. **网络请求串行**：`_loadSources()` → `_loadTracks()` 串行，不可达时累计 24 秒才显示"无曲目"
4. **错误提示冗长**：直接显示 DioException 英文异常，刷屏

### 修复
| 问题 | 修复 |
|---|---|
| 阻塞启动 | `runApp()` 先行，`initAudioService()` 异步后台（不 await） |
| 默认地址 | 真机默认改为 `http://192.168.1.15:18080`（局域网） |
| 串行请求 | `Future.wait([_loadSources(), _loadTracks()])` 并行 |
| 长超时 | connectTimeout 12s → 3s（快速失败） |
| 英文错误 | 友好中文提示（"连接服务器超时（请检查地址与网络）"） |

### 实测启动时间（Playwright，Web 预览）
- 首帧（canvas 出现）：**~1.2 秒**（可达/不可达都在此范围，不再被网络阻塞）
- 不可达服务器：3s 超时后显示友好中文提示，不再卡 24 秒

## 二、图标更换（橙子 + 声音）

用 Python Pillow 绘制（图像生成工具凭证失效后的替代方案），元素：
- 橙色圆角方块背景
- 橙子（米白果肉 + 橙皮 + 绿叶 + 高光）
- 白色声音波形（7 条竖条，中间高两边低）
- 生成 Android 5 档 mipmap（48~192px）+ adaptive 前景 + Web icons + favicon
- 图标文件：`app/android/app/src/main/res/mipmap-*/ic_launcher.png`、`app/web/icons/*`
